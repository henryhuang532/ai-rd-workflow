# Test Cases

Test case files live here as `TASK-YYYYMMDD-NNN-test-cases.md`.

Each acceptance criterion must map to at least one test case. Test cases must record prerequisites, data, steps, expected result, actual result, status, and evidence.

During requirements precheck, prepare only the needed candidate scenarios and missing expectations; unresolved rules remain conditional and draft/not_run. Expand the confirmed scope after decisions converge. Formal QA follows current-version independent Code Review and requires qa_execution receipts bound to requirements_sha256; precheck and document checks cannot satisfy it.
